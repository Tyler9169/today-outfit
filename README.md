# 今天穿什么 · 手机穿搭网站

手机优先的联网网站，适用于 iPhone Safari 和安卓 Chrome。使用现有 Sites 项目发布，当前权限为公开访问，所有人可打开网站。GitHub Pages 和原生入口作为历史代码保留，不属于本次发布目标。

## 使用与数据

- 批量选择照片，每张一件衣服，每次最多 30 张、队列最多 100 张、单张最多 20 MB。照片需能被浏览器解码；无法解码的 HEIC 等文件请转换成 JPG、PNG 或 WebP。
- 识别结果需逐张确认；可修改类别、颜色及自己了解的适用条件。未配置识别时可直接手动录入。
- 按场景、天气或手填温度、雨天和活动地点推荐；可固定单品、局部替换、收藏及重新应用。标记待洗的衣服不会进入新推荐。推荐是规则建议，不是视觉审美或保暖保证。
- 衣橱、照片、收藏与最近穿着记录保存在当前浏览器 IndexedDB，数据库沿用 `my-wardrobe`。不自动跨设备同步；不同网址、浏览器的数据相互独立。
- 换设备或清理浏览器前导出含照片的 JSON 备份。导入支持 v1/v2，默认合并去重；ID 冲突另存并映射收藏。替换全部必须确认。衣物和状态使用同一事务，失败回滚。
- 页面不提供离线模型、离线语音或原生安装包。旧网站缓存退役时仅清理对应缓存，不清理 IndexedDB。

## 识别配置

服务端 `/api/recognize`：GET 查询配置是否完整，POST 接收压缩 JPEG 并调用兼容 Chat Completions 的视觉服务。配置查询不返回密钥。

在 Sites 的生产环境变量中配置 `VISION_API_URL`、`VISION_MODEL`、`VISION_API_KEY`（密钥必须标记为 secret），重新部署使其生效。本地开发使用 `.dev.vars`，参照 `.dev.vars.example`，不得提交真实密钥。

当前生产识别配置为空。未接入真实模型，不将单元测试的模拟响应当作真实识别验证；手动录入可以独立使用。

## 开发与检查

使用 Node.js >=22.13，保留 npm 和现有 lockfile：

```sh
npm ci
npm run dev
npx tsc --noEmit --incremental false
npm test
npm run build
```

测试覆盖识别响应、取消、缺少配置、推荐锁定与替换、属性评分、收藏失效清理、备份冲突映射和 IndexedDB 回滚。浏览器检查使用隔离的本地地址和测试图片，不修改真实衣橱。

## 发布

沿用 `.openai/hosting.json` 中原 Sites project_id，通过 Sites 工作流验证、构建、保存和部署；不用 GitHub Pages 或 Capacitor 构建发布本网站。发布后以 Sites 成功状态返回的网址为准，所有人可用手机浏览器打开，衣橱仍各自保存在访问者的浏览器中。

桌面浏览器的窄屏检查不等于 iPhone/安卓真机认证。真实设备的照片选择、文件下载和存储限制仍需实机确认。

## 天气、照片特征与穿搭偏好（2026-10-07）

- 点击“使用当前位置”才请求浏览器定位；近似坐标保留两位小数后直连 Open-Meteo，不持久保存。也可输入城市名，选择正确的省份/国家。
- 预报显示当地时间的 3/6/12 小时时段，取体感最低温、最高降雨概率和最大风速；核对并点击应用后用于搭配。降雨概率达到 40% 作为雨天条件。数据超过 30 分钟需重新获取，手动修改天气会退出自动条件。定位、网络或数据失败都保留手动输入。
- 上传衣服照片可返回版型、图案、风格、领型、袖长和衣长建议。只有勾选照片特征确认后，版型和风格才参与规则评分。AI 不覆盖手动修改，也不会自动入库。
- 材质标签用单独的照片识别模式读取，先展示原文与建议，再由用户填入、核对确认；也可手填。标签照片仅临时预览，保存成分文字、来源和确认状态，不保存标签原图。确认成分会在推荐说明中展示，不能单凭成分推断保暖、防雨或真实合身度。
- “我的风格与穿着需求”支持年龄段（可选）、风格、版型、行走舒适/通勤整洁和搭配灵感。年龄仅调整建议文案，不改变评分或限制衣物；各年龄段都能选所有风格。不从照片推断年龄、性别或身材。
- 面向成年人的日常与通勤；2026 秋冬资料核对于 2026-10-07，来源为 [Vogue 9月28日趋势文章](https://www.vogue.com/article/fall-winter-2026-fashion-trends)。将柔和剪裁、比例变化和叠穿转为可选衣橱规则；不代表持续联网学习或模型训练，也不将某一地区的秋季趋势当作各地天气。
- 全身照分析与从反馈学习偏好尚未实现；目前偏好由用户主动设置。只支持既有上衣、裤子、鞋子、外套类别，裙装仍待后续扩展。
- 新字段继续使用原数据库，旧衣物无需迁移；v2 备份包含这些字段与偏好。合并导入保留当前偏好，确认替换时应用备份偏好。旧备份采用默认偏好。

验证：14 项自动测试与类型检查通过；隔离浏览器已验证杭州实时天气、确认特征与材质保存、刷新恢复。识别与标签测试使用模拟响应，真实视觉凭据尚未配置。手机窄屏属于桌面模拟，未做 iPhone/安卓真机定位、照片和下载验证。

本轮内置浏览器能生成备份链接，但下载等待接口超时，未确认新文件落盘；新字段已通过备份解析/合并规则测试。原版照片备份往返已有检查记录，仍建议在目标手机上试一次导出与导入。
